# PROJECT.md

## Name
Patch Ritual

## Category
Release experience platform

## One-line description
Turn patch notes into a launch moment.

## Core user
Solo indie creator with a small but engaged community.

## Core loop
Ship update -> generate ritual -> publish -> share -> community reacts

## MVP promise
A solo creator connects GitHub, selects a release, adds a bit of vibe input, and publishes a short branded release ritual that fans can explore and react to.

## Product posture
Not a changelog generator.
Not a community platform.
Not a website builder.
Not a devops tool.

## Success signal
Creators publish repeatedly because the ritual is faster and more memorable than normal patch notes.

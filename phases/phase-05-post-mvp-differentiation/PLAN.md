# Claude Code Phase Plan

## Objective
Add only the highest-value improvements after the MVP loop is validated.

## Scope
- ritual archive
- better social sharing
- saved creator defaults
- better change ranking
- optional voice-note input

## Non-Goals
- live events
- extra integrations
- team features
- deep builder systems

## Inputs
- MVP usage feedback
- analytics learnings
- creator interviews or pilot feedback

## Deliverables
- prioritized post-MVP slice plan
- one improvement wave at a time

## Dependencies
Phase 4 and real usage signal

## Execution Waves
### Wave 1
- validate top pain points

### Wave 2
- implement highest-ROI improvement

### Wave 3
- measure effect before adding more

## Acceptance Criteria
- every added feature strengthens publishing speed, ritual memorability, or audience response
- no feature broadens the product into CMS, devops tool, or social network territory

## Verification
- compare metrics or pilot feedback before vs. after each improvement

# Patch Ritual — Claude Code Starter Pack

This pack turns the supplied product concept into a Claude Code-native repo blueprint.

Use this pack as the Phase 0 bootstrap:
1. Copy these files into the new repository.
2. Scaffold the actual app/runtime code into `apps/web`.
3. Execute phases from `ROADMAP.md`.
4. Use the skills in `.claude/skills/` to plan, implement, verify, and refresh state.

This pack is intentionally optimized for:
- solo-builder execution
- low token waste
- durable file-based state
- a thin orchestrator + a few strong specialists
- constrained MVP delivery
